# CodeCraft — Web page template

A responsive HTML and CSS practice page inspired by the exercise topics: web technology, C programming, and Java. The design uses a sticky navigation bar, a hero section, course cards, alternating lesson sections, and a footer.

## Features

- Semantic HTML5 structure and accessible navigation labels.
- Responsive layout for mobile, tablet, and desktop.
- Mobile navigation toggle with an `aria-expanded` state.
- Search field filters the course cards by title, language, or description.
- Locally stored SVG illustration; no framework or image CDN required.

## Run

Open `index.html` in any modern browser. Search and mobile navigation work without a build step.
